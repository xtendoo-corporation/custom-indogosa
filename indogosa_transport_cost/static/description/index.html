Indogosa Costos de Transporte

Este módulo permite gestionar los costos de transporte basados en el volumen de productos en órdenes de venta de Odoo 17.0.

Características principales

  • Añade un campo "Coste Transporte" en la ficha de cliente que es visible en la vista lista
  • Agrega el campo "Coste Transporte" en las órdenes de venta, autocompletado desde el cliente
  • Calcula automáticamente el total de litros por línea multiplicando el volumen del producto por la cantidad
  • Calcula el costo de transporte por línea dividiendo el coste de transporte entre el total de litros
  • El valor del coste de transporte puede ser editado en cada orden de venta específica

Uso

  1. Configure el "Coste Transporte" en la ficha del cliente
  2. Al crear una nueva orden de venta, el valor se cargará automáticamente al seleccionar el cliente
  3. Cuando se agregan productos a la orden, se calculará automáticamente el "Total Litros" y el "Coste Transporte/Línea"
  4. Si es necesario, puede modificar el "Coste Transporte" directamente en la orden de venta
